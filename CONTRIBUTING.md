# Contributing to Jaamejam

City records live at `data/cities/<id>.yaml`; polity records live at `data/polities/<id>.yaml` with dated geometry in `data/polities/geometry/`; regional name records live at `data/regional-names/<id>.yaml` and add map labels without borders. The filename is the stable ID and the directory supplies the entity type, so neither `id` nor `kind` belongs in a record. Read the [city data schema](docs/cities.md), [polity data schema](docs/polities.md), or [regional names schema](docs/regional-names.md) before editing.

Attach source IDs to each dated presence, label, location, border, and description entry as applicable. Explain where a representative point or territorial outline comes from, especially when historical geography is uncertain. Regional name points position text and do not imply a capital or boundary. Date ranges are display intervals supported by cited evidence, not claims of exact foundation, abandonment, or frontier change. City level is an editorial map size and label-zoom choice. Run `pnpm data:build` to validate and compile the contributed YAML and GeoJSON; edit source data, not the generated `public/atlas/` files.

For a pull request, explain what changed, where and when it applies, and why. Link reliable sources for additions, corrections, and deletions, ideally with page numbers or stable URLs. Call out uncertainty and conflicting accounts. Keep each pull request focused enough to review. Agents are welcome to prepare proposals and pull requests, but the person submitting one is responsible for checking every claim, geometry, citation, and license compatibility. Core maintainers review and approve changes before merge. Run `pnpm typecheck` and `pnpm generate` before submitting.

Project-authored data contributions are submitted under CC BY 4.0 with credit to Jaamejam Contributors. Code contributions are submitted under PolyForm Shield 1.0.0. Do not submit third-party material unless its license allows the proposed use; identify such material and its license in the pull request.
